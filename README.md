# Afunky Noodles Website

Responsive food menu and WhatsApp ordering website for GitHub Pages.

Includes food photos, orange theme, cart, WhatsApp ordering, and OPay bank transfer details: Funky Aduke — 7081851165. Primary WhatsApp: 07081851165; alternate: 08038084081.

## Publish on GitHub Pages
1. Unzip this package.
2. Create a GitHub repository (for example, `afunky-noodles`).
3. Upload `index.html`, `README.md`, and the whole `images` folder to the repository root. Keep the folder structure intact.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
6. Wait for publishing and open the URL shown in Pages settings.

## Before sharing
Menu prices are examples; edit them in `index.html` to match your real prices. Photos are illustrative. The website does not automatically verify bank transfers, so confirm payment yourself. WhatsApp orders open the primary number.
